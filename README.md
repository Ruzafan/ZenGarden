# 枯山水 Jardín Karesansui

Un jardín zen japonés interactivo en una sola página (`index.html`), sin dependencias.

- **Rastrillo**: arrastra para dibujar surcos (3, 5 u 8 púas).
- **Ondas**: mantén pulsado para crear círculos concéntricos.
- **Piedra**: toca para colocar una piedra, arrástrala para moverla, tócala para quitarla.
- **Alisar**: borra los surcos con la mano.
- **Empezar**: alisa todo el jardín.

El sonido de la arena, el viento y la campana se generan en directo con Web Audio.
Atajos: `1`–`4` para herramientas, `S` para el sonido.

Para verlo, abre `index.html` en el navegador (o actívalo con GitHub Pages).
